TASK: Оцени ответ модели по 5 критериям, каждый по шкале 0–2.

КРИТЕРИИ:
1. task (следование задаче): 0 — задача не выполнена; 1 — частично; 2 — полностью.
2. factual (фактическая осторожность): 0 — есть выдуманные факты; 1 — спорные допущения; 2 — факты не придуманы.
3. format (формат): 0 — нарушен; 1 — небольшие нарушения; 2 — соблюдён.
4. completeness (полнота): 0 — важные элементы пропущены; 1 — частично; 2 — все обязательные элементы есть.
5. uncertainty (работа с нехваткой данных): 0 — уверенный вывод при недостатке; 1 — упомянута неопределённость; 2 — перечислено, каких данных не хватает.
